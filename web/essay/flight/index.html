Tiling on the fly

the window that follows the glider

Monolithic verification tops out. The radius-768 boards of the hunt were already luxurious; the largest patch run natively so far, radius 1024, holds 3.6 million tiles, takes 100 seconds to generate — and the engine then steps every one of them each generation while a dozen are alive. The costs scale as radius² for the board and radius³ for the flight (r² tiles stepped for each of the ~2r generations of the crossing). But a glider does not need a million-ring board; it needs the few dozen rings around itself, freshly tiled, forever.

Deterministic addressing — The board's founding promise — is what makes that possible. Any tile's address can root a patch, so the instrument keeps a small window (radius 24 in the campaign) centred near the glider, and when the glider nears the edge it hops: pick a tile beneath the glider, take its address as the new root, regenerate the window, carry the live states across, and discard the old world entirely. Soundness is a margin invariant, not a hope: a hop is triggered while the glider is still far enough from the window edge that no cell the update rule ever reads has a truncated neighbourhood. Memory is constant no matter how far the flight goes; the hop cost grows only with the length of the address — logarithmic in distance — and window regeneration dominates, so the smallest sound window wins.

Two controls make it an instrument rather than a trick. First, windowed flight against monolithic replay: the same glider flown both ways agrees state for state along the whole path — the window is not an approximation. Second, geometry: each hop places the new window in the old one's frame by a rigid motion computed from the tiles the two windows share, and every rotation lands on the tilings' 30° orientation set to within 10⁻¹³ of a degree (every tile sits at one of twelve orientations 30° apart, so a correct motion between windows can only rotate by a multiple of 30°) — and the frames compose in double precision, so even summed over every hop of a million-ring flight the rounding stays a hundred-thousand times below the millidegree headings that The survey will spend.

The picture to hold: the tiling exists only where the glider has been. A launch window, a corridor of retired windows, and beyond that — nothing.
